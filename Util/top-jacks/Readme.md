# TOP Jacks


This is a pcb allowing the input, output and power jack to be mounted at the top of the enclosure, instead of having power at the top, and jacks mounted on the side.   This simplifies the wiring.   I put the diode on this as well so that all pedals get polarity protection.   The jacks used from taydaelectronics: 

6.35mm 1/4" Right Angle Mono Female Connector Thread Lock Panel Mount CK635008,  SKU: A-6976

For this to work and have it above the 16mm pots, you have to drill it as close
to the bottom of the enclosure as you can get.
