# Umble


This is from Runoffgrove Umble, and is based on that schematic.

This pedal is verified.  It is very loud.  You must adjust the biases
to around 4.5v on pin3 of each trimmer.

Out of an enclosure it has a lot of noise, which I think is common for
higher-gain pedals.   All 5 controls seem to work the way that they are
intended.

This only has footprints for SMD because I did not think there was enough
room for a through-hole and SMD.    I soldered on the J201 first, and then
used other pads on the empty pcb to test that the soldered J201s were
functional.  All 4 tested out as NJFET with a peak tester.

Sourcing all the pots with a RG097 footprint was a bit of a PITA, but
I do love how tight these are when it is all boxed up.

Not boxed yet, tho.
