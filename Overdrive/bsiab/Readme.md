# bsiab

Brown sound in a box.   

Tagboardeffects site introduces it as:


> Brown Sound In A Box version
> 2 (BSIAB2) is an excellent distortion pedal designed by Ed
> Guidry. Based on the AMZ MiniBooster cascading work done by Jack Orman
> and further refined by Aron Nelson and Doug Hammond.

> This is one of the best heavy Marshall-type distortion boxes that
> we've heard and it also performs very well on low drive setting

The schematic here is based on the General Guitar Gadgets BSIAB2 pedal

Very nice sound.
