

# Dr Boogieclone


This is based on the Mesa Boogie Dual Rectifier Solo Amplifier.   It is a
high-gain overdrive pedal.   I think it is designed by ElectraTabs over
on the  DIYStompboxes forum. 

This is the 2nd version of the board.
The original version worked too, but the
pots were wrong footprint, so they increased anti-clockwise.   The build
was done with MMBFJ201 JFETs.  This has dual footprints for the JFETs.
These were soldered in first, and tested using pins in the
through-hole part of the footprint.    The main deviation on my
build is an A25K footprint in the smaller RK09 potentiometers is apparently
unobtainable, so a B20K was used instead.

This is sized for a 125B.   Hope it fits.

I had thought, on first testing, that this sounded splatty and hugely over 
distorted, but I had guitar on max volume.    Turning it down a bit made it
sound so much better.

Apparently the trimpots need to be adjusted for 4.5 on the drain of
the corresponding JFET.   I haven't done that yet; all the trims are at 50%.

Very nice high-gain overdrive.    I now have 3 builds prior in a row on the
box-of-shame, so it was nice to hear this light up!!!!
