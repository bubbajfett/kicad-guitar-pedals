Big Muff Pi 2 clone 

This is based on a (modified?) Big Muff Op-amp version, that is the "modern
op-amp version of the EHX big muff pi".    

It is quite a bit more aggressive than the older, discreet transistor
BMP versions I've tried.

This is  verified.    At high sustain, it does motorboat a little in the build
I have.

Requires KICAD 7
