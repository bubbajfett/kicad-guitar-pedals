
# 900 Fuzz

This is a clone of the 900 Fuzz by Fairfield Circuitry.

The first build had a "non-connected" base of Q4. I missed it, and
none of the kicad rules-checker caught it, or I ignored it.   Anyway,
the 2nd try I was more careful not to ignore any ERC errors.

This was based on the Pedalpcb NeinFuzz schematic, which does not specify the JFET.    Dirtboxlayouts shows J201
