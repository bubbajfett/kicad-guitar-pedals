# ToneMachine

Clone based on Foxx Tone machine

Verified, but ***possible issue with tone knob***.

Changed font size, going to try to run these at jlpcb, and the size
I've been using is below their minimum.

Original schematic used did not include a 100u electrolytic on the
9v line, but the tagboardeffects build did, so I added this into the
layout.    I bodged this onto the underside of the board.

The transistors used in the build were 2n3904.    And for the germanium
diodes, BAT42 were used.   Reading the discussions online about this,
the choice of diode matters more here than most.   The sound of this is pretty
cool.    With the octave switch closed, you get a much different sound
that is does not sound good with any chord combos, but which does give an
octave effect.    With the switch open, it has a very nice distortion that gets
a bit splatty when as you turn up the guitar volume knob.  

On testing this build I noticed the tone control, when turned toward pin1,
lost a lot of volume.    I am thinking this is a build issue as the schematic
matches a number of the online schematics and build docs I have found online.
Still researching this one.
